# incoming

Drop photos for the site here (on GitHub: open this folder, then *Add file → Upload files*).
They aren't published as they are: Claude resizes them, moves them into `img/` and adds them to `content.json`,
then clears this folder again.

Tip: one subfolder per project keeps batches apart, e.g. `incoming/a-matter-of-concrete/`. To make a subfolder
while uploading on GitHub, upload into this folder and rename a file to `a-matter-of-concrete/name.jpg` — or just
upload here and say which project the photos are for.
